# Interactive diagrams

Standalone, explorable HTML views of agentblocks (built with Archify). Open the
`.html` files in a browser: pan, zoom, search, follow a path, and click a node's
`SRC` badge to jump to the exact code file and lines it was drawn from.

| View | What it answers |
|---|---|
| [agentblocks-architecture.html](agentblocks-architecture.html) | What the system is made of and how the parts connect |
| [agentblocks-flow.html](agentblocks-flow.html) | One turn, end to end, as a sequence of calls |

Each `.html` is rebuilt from its `*.candidate.json` with Archify; edit the JSON, not the HTML.
